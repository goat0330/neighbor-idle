# Community icon assets

These local SVG assets are adapted from [Lucide](https://lucide.dev/), an open-source outline icon set released under the ISC License.

The files are kept local so Taro can bundle them into the WeChat mini-program without a runtime icon dependency. Orange `*-active.svg` files use the product accent `#FF7433`; the neutral variants use `#6F706B`.

`share.svg` uses the lightweight outbound/share shape from Lucide's `external-link` reference, with the same neutral stroke as the other secondary actions.
