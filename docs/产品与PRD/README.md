# 邻里闲置｜产品与交付索引

这里是当前正式产品基线的入口。代码以 `apps/codex-taro-app` 为准，CloudBase 云函数和数据契约在 `apps/workbuddy-app` 与接口文档中维护。

## 当前冻结内容

- 产品名：邻里闲置。
- 底部导航：`闲置｜求购｜＋发布｜消息｜我的`。
- 统一亮色：`#FF7433`，只用于价格、当前状态、中央发布和关键 CTA。
- 主链路：附近浏览 → 商品/需求详情 → 1 对 1 私聊 → 按需申请联系方式 → 对方同意后展示已授权联系方式。
- 登录与资料：首次打开仅静默 `wx.login`；首次发布或聊天时按需使用微信头像、昵称和手机号能力，微信号手填且选填。
- 群入口：只展示附近生活圈的安全占位入口；没有可用群或接口失败时隐藏/轻提示，不阻断浏览、发布和私聊。

## 正式验收路径

```text
apps/codex-taro-app
  → npm run typecheck
  → npm run build:weapp
  → D:\wxdev\community-idle
  → 微信开发者工具 / 真机
```

H5 只用于快速检查布局，不替代微信开发者工具中的交互和构建验收。`review/` 与 `review*.zip` 是本地生成的临时预览产物，不作为源码发布内容。
