# Figma 设计决策契约

> 当前还没有提供具体 Figma 文件链接或节点 ID。本文件是 P3/P4 参考图到代码之间的临时契约；拿到 Figma 后，需要以 Figma 的页面、变量和组件为最终依据校准。

## 体验方向

- P4 是独立封面入口：先表达“邻居优先、离得近、今天就能拿走”，再进入闲置搜索。
- P3 是闲置搜索页：顶部搜索与定位，下面是双列商品卡片，点击整张卡进入详情。
- 详情页承接“我想要 → 聊天议价 → 约定自提”，交易后进入互评。
- 发布和求购表单使用大尺寸输入框，保证中文商品名、价格和描述完整可读。

## 视觉 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `paper` | `#F7F5EF` | 页面底色 |
| `ink` | `#173B34` | 主文字和主按钮 |
| `mint` | `#DCEBD9` | 认证/位置提示背景 |
| `coral` | `#EB8055` | 价格、强调和行动提示 |
| `line` | `#DEDCD2` | 边框和分隔线 |
| `radius-card` | `28px` | 商品卡片 |
| `radius-control` | `18px` | 输入框和按钮 |

## 动效原则

- 封面首屏使用轻微 stagger reveal，不影响启动速度。
- 商品卡点击使用短促的 scale/opacity 反馈。
- 消息未读只使用明确的红点和会话预览，不使用无依据的系统推送承诺。
