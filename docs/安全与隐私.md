# 安全与隐私基线

- 默认只展示小区名、相对距离和公共自提点，不展示楼栋门牌、精确坐标、手机号或微信号。
- 手机号属于敏感联系方式：只在用户主动点击手机号授权并且卖家明确批准联系方式申请后，向会话双方返回；平时只返回是否已设置和脱敏值。
- 微信号通过独立审批状态机交换；请求者、批准者和时间留痕，支持拒绝、撤回、拉黑和举报。
- 前端违禁词检查仅改善体验；云函数必须调用微信内容安全能力，并对文本、图片和修改操作重复审核。
- 禁止药品、烟草/电子烟、枪支弹药、管制器具、非法账号与服务等；命中后进入拒绝或人工复核。
- 所有写接口从云端上下文读取用户身份，不信任客户端传入的 openid、角色、价格归属或认证状态。
- 云数据库按最小权限配置；会话和联系方式仅双方可访问，管理员操作保留审计记录。
- 公开仓库不保存真实地图 Key、CloudBase 环境、正式 AppID、管理员 openid、客服微信或用户数据。
- 手机号授权 code 只在云函数内即时消费，不写入数据库、日志或前端状态；真实手机号仅存在 `users` 私有字段。
- 自提优先推荐门卫、快递柜旁、社区服务站等公共区域，并持续提示验货后成交、不要提前转账。
