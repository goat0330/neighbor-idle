# 05｜视觉验收清单

## 首页
- [ ] 页面主背景是暖灰，不是橙色大底
- [ ] 搜索和社区同一层
- [ ] 分类为文字型 Tab
- [ ] 无“免费送”
- [ ] ProductCard 无重阴影
- [ ] 卖家头像/昵称清晰但不抢商品
- [ ] 小区名比纯距离更有存在感
- [ ] `问问卖家` 小于价格视觉权重
- [ ] 五栏完整
- [ ] `发布` 居中且突出

## 求购
- [ ] 不复制商品双列卡
- [ ] 显示头像/需求/预算/小区/时间
- [ ] `我有这个` 为轻动作
- [ ] 可直接进入会话

## 消息
- [ ] Row 是商品会话，不是联系人
- [ ] 点击整行直接聊天
- [ ] 无大审批按钮
- [ ] 状态标签克制
- [ ] 不重复社区地址

## 我的
- [ ] 头像/昵称/社区身份轻量
- [ ] 联系方式设置只有一处
- [ ] 在售/已出/收藏紧凑
- [ ] 我的在售为管理列表
- [ ] 标记已出不是大橙按钮

## 商品详情
- [ ] 首图够大
- [ ] 商品名/价格第一屏可见
- [ ] 卖家身份与社区位置明确
- [ ] 自提信息清楚
- [ ] 有快捷提问
- [ ] 底部只有收藏 + 问问卖家核心动作
- [ ] 无购物车/购买/平台支付

## 全局
- [ ] `#FF7433` 只用于重点
- [ ] 页面没有第二套高饱和主色
- [ ] 卡片边界轻
- [ ] 圆角不过量
- [ ] 页面不是“缩小版闲鱼”
