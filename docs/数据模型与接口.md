# 数据模型与接口

## 核心集合

| 集合 | 关键字段 | 访问原则 |
|---|---|---|
| `users` | openid、昵称、communityId、building、verificationStatus、creditTags、wechatId | 微信号永不随公开资料返回 |
| `items` | owner、标题、描述、图片、价格、分类、经纬度、模糊地址、状态、审核状态 | 公开接口只返回模糊位置 |
| `wants` | owner、标题、预算、分类、描述、过期时间 | 仅展示有效且审核通过记录 |
| `conversations` | itemId、participantIds、lastMessage、unread | 仅参与者可读 |
| `messages` | conversationId、sender、类型、内容、审核状态、时间 | 仅参与者可读写，服务端校验 |
| `contact_requests` | itemId、buyerOpenid、sellerOpenid、reason、status、时间 | 仅双方可读，只有卖家可批准 |
| `transactions` | itemId、buyer、seller、自提时间、公共点、状态 | 不保存私聊后的付款凭证 |
| `reviews` | transactionId、from、to、标签、文本 | 一单双方各评价一次 |
| `reports` | reporter、targetType、targetId、reason、evidence、status | 仅举报人和管理员可读 |

## 联系方式状态机

`pending → approved | rejected`，双方任一方可将有效授权变更为 `revoked`。服务端仅在 `approved` 且请求者属于交易双方时返回微信号。任何列表、搜索、消息摘要接口都不返回微信号。

WorkBuddy 后端参考实现：`apps/workbuddy-app/cloudfunctions/contact`。Taro 端当前用本地状态演示完整交互，接云时保持相同状态与字段即可。

## 消息提醒

站内未读数始终保留；订阅消息只在用户主动授权后、针对一次具体事件使用，例如“收到新留言”“卖家同意交换联系方式”“自提时间临近”。授权拒绝不影响站内消息，也不使用营销通知冒充交易提醒。
