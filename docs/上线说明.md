# 上线说明

## GitHub

公开仓库：`https://github.com/lalalawa/neighbor-secondhand`

推送后，协作者可分别拉取 `workbuddy/develop` 和 `codex/develop`，再按 `docs/协作规范.md` 创建本地 worktree。

## WorkBuddy 版本

1. 用微信开发者工具打开 `apps/workbuddy-app`。
2. 配置正式 AppID 和 CloudBase 环境 ID。
3. 部署 `cloudfunctions` 下的云函数并初始化数据库。
4. 复核集合权限、管理员 openid、审核策略和隐私说明。
5. 配置文本/图片内容安全审核、订阅消息模板和客服入口。

## Codex Taro 版本

```bash
cd apps/codex-taro-app
cp .env.example .env.local
npm ci
npm run typecheck
npm run build:weapp
```

在 `.env.local` 写入 `TARO_APP_TENCENT_MAP_KEY` 和 `TARO_APP_CLOUD_ENV`，把 `dist` 导入微信开发者工具后配置正式 AppID。正式接后端时，优先替换 `src/services` 的实现，不要在页面组件中直接写云函数调用。

## 必须由账号管理员完成的上线动作

1. 在微信公众平台确认主体、服务类目与隐私保护指引，并声明定位、相机、相册、剪贴板的用途。
2. 在腾讯位置服务控制台将 Key 绑定正式小程序 AppID，限制可调用接口、来源和日配额。
3. 创建 CloudBase 环境和集合，客户端权限设为所有用户不可读写；部署 `user/conversation/contact/login/item/want/favorite/message/community/initdb` 云函数，并创建文档列出的复合索引。
4. 申请交易型订阅消息模板，仅在用户主动触发后请求授权，不做无关营销提醒。
5. 使用两个真实微信账号覆盖：拒绝/允许定位、拍照与相册、弱网、地图拖拽、双向私聊与未读、买家申请微信、卖家未设置微信时禁止批准、批准/拒绝/撤回、非会话成员越权访问、举报与拉黑。
6. 提交平台审核；审核通过后由管理员点击发布。GitHub 上线不等于微信小程序上线。

## 发布前检查

- 违禁品关键词和图片审核能拦截药品、烟草、电子烟、管制刀具、枪支弹药等内容。
- 不公开完整门牌号和手机号，交易地点使用公共区域。
- “消息提醒”必须基于站内未读状态、用户主动授权的订阅消息和群转发，不把普通推送描述成微信主动通知。
- 二手交易、个人信息处理、内容安全和平台经营主体资质需在正式发布前由运营方复核。
